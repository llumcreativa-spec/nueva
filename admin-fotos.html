Subir fotografías y logotipo

Usa este panel como acceso separado para seleccionar y revisar imágenes. Después, guarda los archivos en el hosting exactamente en las rutas indicadas para que el sitio público los cargue.

Importante: una página HTML estática no puede guardar archivos por sí sola en el servidor. Para una carga real con botón “Subir”, el hosting debe tener un backend privado, FTP, cPanel, administrador de archivos o protección por contraseña del servidor.

1. Logotipo

Selecciona el archivo LOGOTIPO.jpg para previsualizarlo antes de colocarlo en el hosting.

2. Fotografías

Selecciona fotografías de procesos, moldes, piezas terminadas o instalaciones para revisar cómo se verán.

¿Dónde guardar los archivos?

Sube los archivos al hosting usando estas rutas locales. No dependas de imágenes de internet. Respeta mayúsculas, minúsculas y extensiones.

  • Logotipo oficial: public/html/LOGOTIPO.jpg
  • Fotos de procesos: public/html/fotografias/foto-1.jpg, foto-2.jpg, foto-3.jpg, foto-4.jpg

Nota: si el archivo index.html está dentro de public/html, el sitio cargará el logotipo con LOGOTIPO.jpg y las fotos con fotografias/foto-1.jpg, foto-2.jpg, foto-3.jpg y foto-4.jpg.
